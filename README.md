# Insider Threat Analytics Project

This repository will showcase a cybersecurity project focused on detecting insider threats
through behavioral analytics

## Overview
This project demonstrates how a data-driven organization can detect and mitigate **insider cybersecurity threats**—whether malicious, negligent, or compromised—using behavioral analytics.  
It simulates a fictional mid-sized company (~150 employees) where unusual employee activities suggest a potential insider threat.

The repository contains every component needed to showcase a **real-world cybersecurity initiative**:
policies, risk analysis, detection dashboards, training materials, and an incident response playbook.

## Objectives
- Identify risky user behavior using synthetic log data.
- Build policies for **role-based access control (RBAC)** and continuous monitoring.
- Design an **anomaly detection model** to highlight suspicious logins and file accesses.
- Prepare a **risk report**, **training materials**, and a **response plan** to handle incidents.
